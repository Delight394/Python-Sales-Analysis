# Python Sales Analysis

An exploratory data analysis (EDA) project analyzing sales performance, regions, and revenue trends using Python and Pandas.

## Project Overview
This repository contains data cleaning, aggregation, and visualization scripts designed to uncover key business insights from sales transaction data.

## Key Analyses & Features
- **Revenue Metrics**: Calculated total revenue and profit metrics across multiple transactions.
- **Temporal Analysis**: Grouped sales by Month, Year, and Weekday to observe periodicity and trends.
- **Sales Performance**: Evaluated performance breakdowns by `Sales_Rep`, `Region`, and `Customer_Type`.
- **Data Visualization**: Built line plots using Matplotlib to track monthly revenue trajectories over time.

## Tech Stack
- **Python**
- **Pandas** (Data manipulation and grouping)
- **Matplotlib** (Data visualization)

## Repository Structure
- `Sales Analysis.ipynb` — Main Jupyter notebook for data analysis and visualization
- `git_sales_data.csv` — Sales transaction dataset
