# Python Sales Analysis

📌 **Project Overview**  
Exploratory data analysis (EDA) and Python scripts analyzing sales performance, customer behavior, and revenue trends to uncover key business insights from sales transaction data.

🛠️ **Key Libraries & Techniques**  
- **Pandas & NumPy:** Data cleaning, manipulation, and statistical aggregation
- **Matplotlib:** Data visualization and monthly revenue trend discovery
- **Exploratory Data Analysis (EDA):** Investigating temporal periodicity, customer types, and sales rep performance distributions
